# BoolValidation

Проверяет, что значение является логическим.

## Методы

### boolean
Проверяет булево значение. Допустимые значения: `true/false`, `1/0`, строки `1/0/true/false/yes/no/on/off`.

### accepted
Проверяет, что значение принято (`true`, `1`, `yes`, `on`).

### acceptedIf
Проверяет, что значение принято, если `field` равно любому из `values`.
Сравнение значений выполняется строго (`===`).

### declined
Проверяет, что значение отклонено (`false`, `0`, `no`, `off`).

### declinedIf
Проверяет, что значение отклонено, если `field` равно любому из `values`.
Сравнение значений выполняется строго (`===`).

### required/nullable
Доступны, см. required‑сценарии.

Если поле отсутствует, ошибки нет. Для обязательности используйте `PresentValidation`.
Сравнение значений выполняется строго (`===`), регистр важен.

## Сообщения

- `boolean` — поле должно быть логическим значением
- `accepted` — поле должно быть принято
- `accepted_if` — поле должно быть принято, если `{other}` равно `{values}`
- `declined` — поле должно быть отклонено
- `declined_if` — поле должно быть отклонено, если `{other}` равно `{values}`

## Пример

```php
use PhpSoftBox\Validator\Rule\BoolValidation;

$rules = [
    'active' => [(new BoolValidation())->accepted()],
];
```
